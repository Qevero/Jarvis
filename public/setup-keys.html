Jarvis setup keys

This page makes the secret keys Jarvis needs. They're created in your browser and never sent anywhere.

Before you close this page: copy each key into Netlify (and into your password manager). If you reload, you'll get brand new keys and the old ones are gone. That's fine before you've saved them, but once Jarvis is running don't change VAULT_ENCRYPTION_KEY.
